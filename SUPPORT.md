# Support

Babelfish support is best-effort and focused on reproducible compatibility
problems.

Before opening an issue:

1. Check the README compatibility table and app-specific notes.
2. Search existing issues.
3. Reproduce with the latest supported Babelfish version.
4. Collect the Babelfish, OpenClaw, Node, and Python versions involved.
5. Remove credentials, private paths, hostnames, and sensitive plugin data.

Use the bug report form for defects and the compatibility request form for
unsupported source behavior. If the problem occurs entirely inside a
third-party plugin and does not involve Babelfish translation or execution,
report it to that plugin's maintainers.

Report security vulnerabilities privately according to [SECURITY.md](SECURITY.md).
